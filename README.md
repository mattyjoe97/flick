# FLICK

An incremental browser game about an office rubber band war. It starts when Gary in the next cubicle flicks a rubber band at you, and ends (eventually) with you running the building.

This repo holds the **first playable slice**: Stage 1 (Desk Skirmish) and Stage 2 (Cubicle Alliance), about 45–75 minutes of play.

## Play it online

Every push to `main` builds the game and publishes it with GitHub Pages (see `.github/workflows/deploy.yml`). One-time setup: in the repo, go to **Settings → Pages** and set **Source** to **GitHub Actions**. The game then lives at `https://<your-username>.github.io/flick/`.

## Play it locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).

Add `?debug=1` to the URL for a speed control (×1, ×10, ×50) and `window.flick` in the browser console.

## Controls

| Key | Action |
| --- | --- |
| F | Flick at the current target (hold to stretch the band, let go at full stretch for a Perfect shot) |
| S | Scrounge your drawer for bands |
| W | Do your next work task (a ringing phone first). 1–9 answer inside a task |
| O | Order supplies |
| Esc or B | Look busy (the Boss Key spreadsheet) |

Your actual job keeps coming: emails to answer, a desk phone to pick up and transfer, budget sheets to check and expense reports to approve, each a short mini-game. Doing them well pays Salary and lowers Suspicion (quick work earns a speed bonus). Letting the phone ring out, or leaving work waiting so long it's overdue, raises Suspicion, and it won't cool down until you catch up. While a task is open you can't flick, but a walk-by finds you working. Your own rubber band order sometimes turns up in an expense report: approve it for free bands, if you don't mind Accounting noticing.

Getting caught (Suspicion reaches 100) puts a write-up in your HR file, sends your equipped weapon to Mr. Feeney's drawer for 3 minutes (Lost and Found sells it back for half its price), and lets your target regroup. A write-up fades after 10 minutes without getting caught. Three write-ups is Final Warning; get caught again and you're fired: you lose your bands and this stage's progress, keep your weapons, requisitions and team, and HR rehires you on Monday with a clean file.

Coworkers are promoted to Senior and then Lead the longer they're on your team, which makes them better at their role.

While you look busy, the spreadsheet is a mini-game: fix cells with red corners before their fuse runs out. Fixes in a row build a streak that pays more, and fixing one right as Mr. Feeney walks past pays double. The Budget and Headcount tabs unlock as you progress and pay more.

## Commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server with hot reload |
| `npm test` | Simulation tests plus scripted bots that play the whole slice |
| `npm run build` | Production build in `dist/` |
| `npm run build:single` | Everything in one `dist-single/index.html`, easy to share |

## How the code is organized

| Path | What lives there |
| --- | --- |
| `src/sim/content.ts` | All tunable content: weapons, targets, coworkers, requisitions, emails, numbers |
| `src/sim/state.ts` | The game state and a fresh game |
| `src/sim/engine.ts` | The simulation step and every player action |
| `src/sim/mods.ts` | Values derived from upgrades and allies |
| `src/sim/save.ts` | Saving, loading, migration, export and import |
| `src/sim/minigame.ts` | The spreadsheet mini-game: flags, streaks, fatigue, tabs |
| `src/sim/work.ts` | Your job: the work queue, its four task types and their content |
| `src/ui/scene.ts` | The office across the aisle: people, cover, flying bands, Mr. Feeney, clock and light |
| `src/ui/characters.ts` | Every coworker, drawn from shared parts in one style |
| `src/ui/sheet.ts` | The spreadsheet view: column-aware numbers, formulas and totals |
| `src/ui/workview.ts` | The work tray, the ringing phone, and the task cards |
| `src/ui/launcher.ts` | Your hand and weapon: aiming, hold to stretch, Perfect release, snapping |
| `src/ui/art.ts` | Sprite sizes and anchor points (generated by `tools/prepare-art.py`) |
| `art/source/` | Full-size original art (hands, weapons, bands), generated with Astra |
| `src/ui/sound.ts` | Sound effects synthesized in code |
| `src/ui/` (other) | The desk layout, panels, dialogs and input |
| `tests/` | Unit tests and the pacing bots |

The simulation never touches the page, so tests can play the whole game in about a second. Balancing mostly means editing numbers in `content.ts` and running `npm test`, which prints how long each bot took per stage and how often it got caught.

## Art

The hands, weapons and rubber bands are painted sprites. The full-size originals live in `art/source/` (each weapon comes as a loaded and an empty version on a shared canvas, with the wrist at the same spot; the script snaps the ruler in half and draws every weapon at the same scale so your hand never changes size). `python3 tools/prepare-art.py` (needs Pillow) crops them, extends the shirt sleeve, scales them to what the game draws and writes WebP sprites to `src/assets/art/` plus their anchor points to `src/ui/art.ts`. Re-run it after replacing any source image. The Drill-Powered Gatling is already prepared for Stage 3.
